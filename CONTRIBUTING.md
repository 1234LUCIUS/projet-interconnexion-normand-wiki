# Contribuer au wiki

Merci d’améliorer la documentation du Projet d’Interconnexion Normand. Les corrections de langue, procédures de test, retours terrain et traductions sont bienvenus.

## Avant de proposer une modification

Vérifiez les documentations officielles Meshtastic ou MeshCore lorsque la modification concerne leur logiciel. Pour les réglages propres au projet, indiquez clairement ce qui est confirmé, ce qui est proposé et ce qui doit être validé par les mainteneurs.

## Pull request

Une pull request devrait expliquer :

- le problème rencontré ;
- la modification réalisée ;
- le matériel ou la version concernés ;
- la manière dont la procédure a été testée ;
- les informations sensibles retirées.

Ne commitez jamais de clé, mot de passe, QR code de configuration, position exacte d’un particulier ou export complet d’appareil.

## Style

Écrivez en français clair, utilisez des titres courts et donnez un exemple reproductible. Préférez les liens vers les sources officielles. Toute affirmation réglementaire doit être datée ou renvoyer vers une source officielle.

## Gouvernance

Les décisions qui changent le canal, le preset, la politique de position, les passerelles Internet ou les rôles des relais nécessitent une discussion préalable et une trace dans le journal de configuration.

Pour échanger avec les contributeurs, rejoignez le [serveur Discord du projet](https://discord.gg/HnAfYUSU82). Les demandes générales peuvent aussi être envoyées à [projet.interconnection.normand@gmail.com](mailto:projet.interconnection.normand@gmail.com).
