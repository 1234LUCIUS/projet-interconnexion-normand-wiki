Journal des versions et des changements

Cette page suit l’évolution du wiki, de ses contenus et de ses outils de contribution. Elle permet aux nouveaux arrivants de comprendre ce qui a changé et aux contributeurs de retrouver les modifications dans le dépôt open source.

État actuel : le wiki est un projet documentaire vivant. Les numéros ci-dessous désignent des étapes de documentation et non des versions de firmware MeshCore ou Meshtastic. Pour les logiciels et firmwares, consultez toujours les liens officiels indiqués dans les guides.

Version documentaire actuelle

Édition 2026.11 — 21 novembre 2026

Le wiki dispose désormais d’une base éditoriale structurée pour les débutants, les associations, les collectivités et les contributeurs du Projet d’Interconnexion Normand.

  • présentation du projet, de ses objectifs de résilience locale et de son orientation progressive vers MeshCore ;
  • guides MeshCore et Meshtastic, configurations France / Normandie, flashage et installation ;
  • cartes officielles, Observers, couverture radio, points hauts et matériel ;
  • Actualités et Blog avec validation administrateur avant publication ;
  • galerie photo, page « Je veux aider », page dédiée aux collectivités et flux RSS ;
  • formulaires GitHub simplifiés et documentation des contributions.

Comment lire ce journal ?

Les changements de contenu sont publiés après relecture. Les modifications techniques sont conservées dans l’historique Git du dépôt. Un lien « commit » ouvre la modification correspondante sur GitHub ; le lien « historique GitHub » permet de consulter les évolutions ultérieures.

Les informations de configuration radio doivent toujours être vérifiées dans les pages MeshCore ou Meshtastic concernées. Une modification du wiki ne signifie pas qu’un firmware ou un appareil a changé de comportement.

Proposer une amélioration

Vous pouvez signaler une erreur, proposer une correction ou suggérer une nouvelle page depuis le dépôt GitHub. Pour poser une question, rejoignez le serveur Discord officiel ou utilisez le formulaire de contact.
