# Explorer les guides MeshCore et Meshtastic

Les pages sont regroupées selon la question à laquelle elles répondent. Si vous découvrez le projet, suivez d’abord le parcours court ci-dessous. Sinon, choisissez directement un thème.

## Parcours conseillé pour débuter

<ol class="pathway">
  <li><strong>Choisir :</strong> lisez <a href="01-choisir-son-reseau.html">la comparaison MeshCore / Meshtastic</a> selon votre usage.</li>
  <li><strong>Préparer :</strong> suivez le <a href="guide-debutant.html">guide du premier nœud</a> et vérifiez la <a href="01-checklist-materiel.html">checklist de préparation</a>.</li>
  <li><strong>Configurer :</strong> ouvrez ensuite le <a href="meshcore/01-demarrage.html">démarrage MeshCore</a> ou le <a href="meshtastic/01-demarrage.html">démarrage Meshtastic</a>, selon le logiciel choisi.</li>
</ol>

<p class="notice"><strong>À retenir :</strong> MeshCore et Meshtastic utilisent la radio LoRa mais ne communiquent pas directement entre eux. Ne choisissez pas un guide de configuration avant d’avoir identifié le logiciel installé sur votre appareil.</p>
