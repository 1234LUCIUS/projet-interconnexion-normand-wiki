# Dépannage commun

## Méthode

Changez une seule variable à la fois. Notez le modèle, le firmware, la région, le preset, le canal, la distance, l’antenne, l’alimentation et l’heure. Un problème de portée est souvent un problème de configuration ou d’installation avant d’être un problème de puissance.

## L’appareil ne s’allume pas

Vérifiez la batterie, le câble, le courant disponible et l’interrupteur. Si le problème suit le câble, remplacez-le. Si l’appareil chauffe anormalement ou si l’odeur change, coupez l’alimentation et ne poursuivez pas les essais.

## Aucun voisin visible

Vérifiez successivement : antenne connectée, région, preset, canal, rôle, distance, mode avion/Bluetooth et permissions de l’application. Pour Meshtastic, les paramètres LoRa et le canal doivent correspondre. Pour MeshCore, vérifiez le rôle flashé et le client utilisé.

## Le voisin est visible mais les messages échouent

Contrôlez le nom du canal, la clé, l’horloge de test et le chemin radio. Réduisez le message à quelques mots. Recommencez à courte distance avec deux appareils posés à vue.

## Portée insuffisante

Répétez le test dans un lieu dégagé. Vérifiez le connecteur SMA/U.FL, le type d’antenne, le câble coaxial et l’orientation. Comparez avec un autre appareil connu. Ne modifiez pas la puissance ou la région pour contourner un problème matériel.

## Après une mise à jour

Relisez les notes de version, vérifiez les réglages qui ont pu revenir aux valeurs par défaut et restaurez uniquement une sauvegarde fiable. Si le nœud est distant, n’appliquez pas une mise à jour sans solution de récupération locale ou hors bande.

## Informations à fournir dans une issue

Publiez le modèle exact, la version, le rôle, le client, une description reproductible et les essais déjà effectués. Masquez les clés, QR codes, adresses privées, positions précises et identifiants personnels.
