# Code de conduite

Nous voulons une communauté accueillante, technique et respectueuse. Les désaccords portent sur les idées et les mesures, jamais sur la valeur des personnes.

Sont attendus : langage courtois, retours factuels, respect de la vie privée, transparence sur les tests et accueil des débutants.

Ne sont pas acceptés : harcèlement, menaces, divulgation de données personnelles, sabotage volontaire, incitation à contourner la réglementation ou publication de clés et secrets.

Les mainteneurs peuvent demander une correction, masquer une donnée sensible, fermer une discussion ou suspendre temporairement une contribution. Pour signaler un problème de conduite, contactez les mainteneurs du dépôt sans publier d’informations privées dans une issue publique.
